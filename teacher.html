1. Worksheet QR code

Students scan it and the worksheet opens in PagePal. Make one for each worksheet; it doesn’t affect where work is sent. Share the file in Google Drive as “Anyone with the link can view” first.

2. Class QR code for receiving work

Students scan this once; from then on every worksheet they send arrives in your Google Sheet. Teach more than one class? Use the same web app URL and secret code with a different name for each class. Set up the sheet first with the teacher set-up guide (files: PagePal-Inbox.gs, appsscript.json).

After that, the QR code stops connecting new iPads. iPads already connected keep working.

In PagePal: Settings › Scan class QR code

Keeping it safe
  • Show it while students connect, then take it down. Anyone who scans it before it expires can send work to your sheet (they can never read it).
  • At the start of each term, or if the code spreads, run resetCode in Apps Script. Connected iPads then need a new QR code.
  • Open students’ pictures and PDFs in Google Drive’s viewer rather than downloading them, and be wary of web links inside answers.
