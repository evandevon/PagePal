2. Class QR code for receiving work

Students scan this once; their iPad then shows Send to teacher, and work arrives in your Google Sheet. Set up the sheet first with the teacher set-up guide (script: PagePal-Inbox.gs).

In PagePal: Settings › Scan class QR code

Keep this code within your class: anyone who scans it can send work to your sheet. If it spreads, run resetCode in Apps Script and make a new one.
