# The inbox script moved

The script that receives students' work moved to Classroom Inbox:
https://github.com/evandevon/classroom_inbox/tree/main/apps-script (`Classroom-Inbox.gs`, version 6).

Class QR codes are made on the Classroom Inbox teacher page: https://evandevon.github.io/classroom_inbox/

Update an existing PagePal Inbox in place: paste the new script, run `setup`, then Deploy › Manage deployments › pencil › New version. Your class QR codes keep working.
